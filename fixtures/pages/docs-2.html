Ledger.parse(text, options)

Parses a plain-text ledger into an array of Entry objects. Blank lines separate entries, and lines that start with a semicolon are treated as comments.

Parameters

NameTypeRequiredDescription
textstringyesThe ledger source to parse.
options.strictbooleannoThrow on the first malformed line instead of skipping it.
options.currencystringnoFallback currency code for amounts without one.

Return value

An array of Entry objects in the order they appear in the source. When strict is false, malformed lines are collected on the warnings property of the array.

Example

const entries = Ledger.parse(`
2026-02-01 Rent
  expenses:home   600.00 EUR
`, { strict: true });
console.log(entries.length); // 1

Deprecated option

The options.lenient flag was removed in version 3. Use strict: false instead.

Errors

  • ParseError is thrown in strict mode when a line cannot be read.
  • CurrencyError is thrown when an amount has no currency and no fallback is given.
