How do I keep a CSV import from duplicating rows?

Asked 3 weeks ago · Active 2 days ago · Viewed 1,204 times

14

I load a CSV file into a table every night, and some nights the job runs twice. Each run inserts the same rows again, so the table slowly fills with duplicates. The file has no unique column, only a name, a date and an amount.

What is the cleanest way to make the import safe to repeat?

Build a natural key from the three columns and put a unique constraint on it. Then insert with a clause that ignores conflicts, so a second run changes nothing.

CREATE UNIQUE INDEX uniq_row ON ledger (name, day, amount);
INSERT INTO ledger SELECT * FROM staging ON CONFLICT DO NOTHING;

If amounts can legitimately repeat on the same day, add a line number from the file as a fourth column.
